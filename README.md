# 페르시아이야기

어려운 페르시아 역사를, 짧은 한국어로. Persia Stories.

아케메네스 제국의 키루스·다레이오스 1세·크세르크세스, 왕의 길과 페르세폴리스, 그리스와의 전쟁, 알렉산드로스의 짧은 다리, 파르티아와 사산의 길을 잡는 장면, 일상과 신앙, 관련 영화를 정적 페이지로 정리합니다.

같은 나두 역사·신화의 다른 방:

- [나두신화 (Myth)](https://nadoo-myth.vercel.app)
- [일리아스이야기 (Iliad)](https://iliad-stories.vercel.app)
- [그리스이야기 (Greece)](https://greece-stories.vercel.app)
- [로마이야기 (Rome)](https://rome-stories.vercel.app)
- [이집트이야기 (Egypt)](https://egypt-stories.vercel.app)
- [더 초즌 · 성경 (The Chosen · Bible)](https://the-chosen-korean.vercel.app)
- [철학이야기 (Philosophy)](https://philosophy-stories.vercel.app)
- [대한민국이야기 (Korea)](https://korea-stories.vercel.app)
- [나두연표 (Timeline)](https://nadoo-timeline.vercel.app)
- [나두 허브 (Nadoo Hub)](https://tinalinkeom.vercel.app)

## 개발

```bash
npm install
npm run build
npm run dev
```

Next.js 15 App Router, React 19, Tailwind CSS v4, TypeScript. 글 페이지는 빌드 때 정적 생성됩니다.
